# WeatherNow - Weather App

A responsive weather application that fetches current weather data using the Open-Meteo API.

## Features
- Search weather by city name
- Current temperature and feels-like temperature
- Humidity, wind speed, and precipitation
- Loading indicator and error handling
- Responsive mobile-friendly design

## Technologies
- HTML5
- CSS3
- JavaScript
- Fetch API and Async/Await
- Open-Meteo API

## How to Run
Open `index.html` in your browser with an active internet connection.
